# 📊 E-commerce Sales Data Pipeline 

This project builds an automated ETL pipeline to clean, transform, and load e-commerce sales data using Python, Airflow, and AWS S3. 

## 📦 Tools
- Python (pandas)
- Apache Airflow
- AWS S3
- PostgreSQL / Redshift

## 🔄 Workflow Steps
1. Ingest raw sales data
2. Clean & transform using Python
3. Upload to S3
4. Load into database
5. Orchestrate with Airflow
